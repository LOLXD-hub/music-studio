# MCP tool reference

Generated by `npm run docs` from the tool definitions. Every tool takes an `action` and that action's fields. Positions are beats (0-based numbers) or `"bar:beat"` strings.

## studio

Project-level control: status, help, new/open/save, tempo, key, time signature, loop, markers, undo/redo.

### studio `status`

Overview of the project: settings, tracks, length, agent and transport state, capabilities.

### studio `help`

Guides ("workflow", "time", "listen", "realism", "mix", "sfx", "mistakes") or the exact argument schema of a tool action.

| field | type | notes |
|---|---|---|
| `topic` | string | Guide name, or an action name when `tool` is set. |
| `tool` | string |  |

## notes

Write and edit notes. Prefer the compact `text` form for writing music: "C4:1 E4:0.5 G4:0.5 r:1 [C4 E4 G4]:2@80".

### notes `add` · edits the project

Add notes to a track. Give `text` (compact notation, placed at `at`) or a `notes` array. Positions are absolute beats or "bar:beat". Clips are created automatically.

| field | type | notes |
|---|---|---|
| `track` * | string | Track id (t1, t2 ...) or track name. |
| `text` | string | Compact note text, see studio help topic "time". |
| `notes` | object[] |  |
| `at` | number | string | Start position of the text, or an offset added to every note in `notes`. |
| `replace` | boolean | Replace existing notes in the span covered by the new notes. |
| `clip_name` | string |  |
| `velocity` | number | Default velocity for text notes. |

### notes `set` · edits the project

Replace ALL notes of one clip with the given list (absolute beats). Used by the piano roll; also handy to rewrite a clip in one go.

| field | type | notes |

| `clip` * | string |  |
| `notes` * | object[] |  |
